# Lista de Filmes 📽️

Projeto feito para a introdução em react-native 

## 🚀 Tecnologias e Ferramentas Utilizadas
- **Axios 1.8.4**  
- **Expo 52.0.32**  
- **React 18.3.1**
- **Styled Components 6.1.15**

---  

## 📁 Estrutura do Projeto  
```plaintext
├── _components/            # Componentes reutilizáveis da interface
├── _pages/                 # Paginas do projetos  
├── services/               # Configurações do backend
└── routes                  # Logicas de rotas da aplicação 
```
---  

## 🛠️ Instalação e Uso 

**Pré-requisitos**
  - Node.js v18+
  - npm ou yarn

**Instalação**
```bash
  git clone https://github.com/Akcio23/Netflix_mobile.git  
  cd Netflix_mobile  
  npm install
```
**Rodando o Projeto**
```javascript
  npm expo start # ou yarm expo start
```
  Agora, escaneie o QR Code com o aplicativo Expo Go no seu celular.
